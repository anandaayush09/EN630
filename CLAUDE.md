# Agent instructions

This repository follows the engineering protocol in [`docs/agent/PROTOCOL.md`](docs/agent/PROTOCOL.md).

At the start of every session:
1. Read [`docs/agent/Handover.md`](docs/agent/Handover.md) (current state, open issues, next steps).
2. Read [`docs/agent/Constraints.md`](docs/agent/Constraints.md) before moving, adding or publishing any file.
3. Re-read the files you rely on; do not assume earlier work was completed without checking.

At the end of every session, update `Handover.md` (and `Decisions.md`, `Flow.md`, `Testing.md`, `Rollback.md` where relevant).

Never commit, push or delete files unless the user explicitly asks.
